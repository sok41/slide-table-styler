Privacy Policy

Effective date: September 30, 2026 (last updated: October 7, 2026)

This Privacy Policy explains how Slide Table Styler (the "Add-on"), a Google Slides add-on developed by sok41 (the "Developer"), accesses, uses, and handles your data.

Summary

  • The Add-on only works on the presentation you have open, and only changes it when you click Apply.
  • The Add-on does not store your content and does not send it to the Developer or any third party.
  • The Add-on does not use cookies, analytics, or advertising.

Data the Add-on accesses

The Add-on runs on Google Apps Script under your Google account. It accesses the following data only while you use it:

  • Tables in the open presentation — the number of rows and columns, merged cells, column widths, and the text in each cell. The text is read only to decide how to format it (for example, to skip empty cells and to find columns that contain only numbers).
  • Theme colors of the current slide — read when the sidebar opens, to offer them as accent color choices.
  • Your language setting — used to show the menu and messages in Japanese or English.

How the Add-on uses the data

The data is used only to provide the Add-on's features: applying borders, background colors, text styles, alignment, row heights, and column widths to the tables you choose. The Add-on does not use your data for any other purpose.

Google OAuth scopes

ScopeWhy the Add-on needs it
https://www.googleapis.com/auth/presentations To read the tables in the open presentation and change their formatting when you click Apply. Table borders can only be changed through the Google Slides API, which requires this scope. The Add-on only works on the presentation you have open.
https://www.googleapis.com/auth/script.container.ui To show the Add-on's menu and sidebar inside Google Slides.

Data sharing and transfer

  • The Add-on does not transfer your data to the Developer, to any third party, or to any server outside Google. It has no servers of its own and makes no requests to external services.
  • The Add-on does not sell your data, and does not use or share it for advertising, credit or lending decisions, or any purpose other than providing the features described above.

Data protection

Your data is protected by the following mechanisms:

  • Processing only inside Google's infrastructure. The Add-on runs on Google Apps Script and changes your tables through the Google Slides API. Your presentation data is processed only within Google's systems and is never copied to servers operated by the Developer or by anyone else.
  • Encryption in transit. All communication between the sidebar in your browser, Google Apps Script and the Google Slides API uses HTTPS (TLS) encryption.
  • Your own authorization only. The Add-on runs under your Google account with the permissions you grant. It can only act on the presentation you have open, and only when you click Apply. You can revoke access at any time (see "Removing access" below).
  • No stored copies. The Add-on does not write your content to any database, file, cache or browser storage, so there is no stored copy of your data that could be exposed.
  • Restricted access to error logs. Error logs (described below) are kept in the Developer's Google Cloud project, protected by Google Cloud's access controls, and can be viewed only by the Developer's Google account.

Data retention and deletion

  • Your content: not retained. The tables are read only while the Add-on is running, and nothing is kept after the request finishes.
  • Error logs: if an error occurs, a technical error message may be recorded in Google Cloud Logging so the Developer can fix problems. These messages describe the error (and may include internal identifiers of slide objects) but not the text of your tables. Google also records basic execution information, such as the time and whether it succeeded. These records are deleted automatically after 30 days (the default retention period of Google Cloud Logging).
  • Deletion requests: because the Add-on stores no personal data, there is normally nothing to delete. If you have questions about your data, contact us through the link below.

AI and machine learning

The Add-on does not use any AI or machine learning models. Your data is not used to develop, improve or train AI or machine learning models, and it is not transferred to any third-party AI service.

Limited Use

Slide Table Styler's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can uninstall the Add-on from Google Slides at any time (Extensions → Add-ons → Manage add-ons). You can also remove its access from your Google Account at Third-party apps & services. Because the Add-on keeps no data, there is nothing else to delete (see "Data retention and deletion").

This website

This website is hosted on GitHub Pages. GitHub may collect technical information such as IP addresses when you visit; see the GitHub General Privacy Statement. This website itself does not use cookies or analytics.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

For questions about this policy, please open an issue on GitHub Issues.

プライバシーポリシー

施行日：2026年9月30日（最終更新：2026年10月7日）

このプライバシーポリシーは、sok41（以下「開発者」）が提供する Googleスライドのアドオン Slide Table Styler（以下「本アドオン」）が、データにどのようにアクセスし、どのように扱うかを説明するものです。

概要

  • 本アドオンは、開いているプレゼンテーションだけを対象にし、「適用」を押したときにだけ変更します。
  • 本アドオンは、内容を保存せず、開発者や第三者に送信しません。
  • 本アドオンは、Cookie、アクセス解析、広告を使いません。

本アドオンがアクセスするデータ

本アドオンは、利用者の Google アカウントのもとで Google Apps Script 上で動作し、利用中に限り次のデータにアクセスします。

  • 開いているプレゼンテーションの表：行と列の数、結合したセル、列幅、各セルの文字。文字は書式の決め方にだけ使います（空のセルを飛ばす、数値だけの列を見つけるなど）。
  • 表示中のスライドのテーマの色：サイドバーを開いたときに読み取り、アクセントカラーの候補として表示します。
  • 言語の設定：メニューやメッセージを日本語・英語のどちらで表示するかを決めるために使います。

データの利用目的

データは、本アドオンの機能（選んだ表に罫線・背景色・文字の書式・揃え・行の高さ・列幅を適用すること）を提供するためにだけ使います。それ以外の目的には使いません。

Google OAuth のスコープ

スコープ必要な理由
https://www.googleapis.com/auth/presentations 「適用」を押したときに、開いているプレゼンテーションの表を読み取り、書式を変更するため。表の罫線は Google Slides API でしか変更できず、この API にはこのスコープが必要です。本アドオンは開いているプレゼンテーションだけを対象にします。
https://www.googleapis.com/auth/script.container.ui Googleスライドの中に、本アドオンのメニューとサイドバーを表示するため。

データの共有と転送

  • 本アドオンは、データを開発者、第三者、Google 以外のサーバーに送信しません。独自のサーバーを持たず、外部のサービスにも接続しません。
  • 本アドオンは、データを販売せず、広告・与信や貸付の判断など、上に書いた機能の提供以外の目的に使ったり共有したりしません。

データの保護

利用者のデータは、次の仕組みで保護されています。

  • 処理は Google の基盤の中だけ：本アドオンは Google Apps Script 上で動作し、Google Slides API を通じて表を変更します。プレゼンテーションのデータは Google のシステムの中だけで処理され、開発者やほかの誰かが運用するサーバーにコピーされることはありません。
  • 通信の暗号化：ブラウザのサイドバー、Google Apps Script、Google Slides API の間の通信は、すべて HTTPS（TLS）で暗号化されています。
  • 利用者自身の承認の範囲だけで動作：本アドオンは、利用者の Google アカウントのもとで、利用者が許可した権限だけで動作します。対象は開いているプレゼンテーションだけで、「適用」を押したときにだけ動きます。アクセス権はいつでも取り消せます（下の「アクセス権の削除」を参照）。
  • データの複製を持たない：本アドオンは、内容をデータベース・ファイル・キャッシュ・ブラウザのストレージに書き込みません。そのため、流出しうるデータの複製が存在しません。
  • エラーログへのアクセスの制限：エラーログ（下記）は開発者の Google Cloud プロジェクトに保存され、Google Cloud のアクセス制御で保護されており、開発者の Google アカウントだけが閲覧できます。

データの保存と削除

  • 利用者の内容：保存しません。表は本アドオンの実行中にだけ読み取り、処理が終わったあとには何も残しません。
  • エラーログ：エラーが起きた場合、開発者が不具合を直すために、技術的なエラーメッセージが Google Cloud Logging に記録されることがあります。これはエラーの内容を示すもので（スライド内のオブジェクトの内部 ID を含むことがあります）、表の文字は含みません。また Google は、実行日時や成功・失敗などの基本的な実行情報を記録します。これらの記録は30日後に自動で削除されます（Google Cloud Logging の既定の保持期間）。
  • 削除の依頼：本アドオンは個人データを保存しないため、通常は削除するものはありません。データについてご質問があれば、下の問い合わせ先までご連絡ください。

AI・機械学習

本アドオンは、AI や機械学習のモデルを使いません。利用者のデータを AI・機械学習モデルの開発・改善・学習に使うことはなく、第三者の AI サービスに送信することもありません。

Limited Use（利用の制限）

Slide Table Styler による Google API から受け取った情報の利用と転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセス権の削除
